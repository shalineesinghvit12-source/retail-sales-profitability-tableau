# Data

The published Tableau dashboard analyzes retail business data across product type, gender, production cost, production volume, location, revenue, and number of products sold.

The live Tableau Public visualization is the primary source for exploring the project interactively. The repository also includes the packaged Tableau workbook in workbook/Retail-Sales-Profitability-Dashboard.twbx. The TWBX contains the workbook and an embedded Tableau Hyper extract, so no separate raw data file is required to open the packaged project.
